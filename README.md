# School ERP

Monorepo (pnpm workspaces + Turborepo).

```
apps/
  web/        # frontend (to be scaffolded)
  api/        # backend (to be scaffolded)
packages/
  shared/     # shared types/utils
  tsconfig/   # shared TS config
docs/         # product & architecture notes
```

## Getting started
```bash
pnpm install
pnpm dev
```
