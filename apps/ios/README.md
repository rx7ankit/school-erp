# Slov for iOS (parent app)

SwiftUI, Swift 5.10+, MVVM with `@Observable`, iOS 17.0 minimum. No third-party packages.
Spec: `docs/mobile/parent-app-spec.md`. Tokens: `packages/tokens/tokens.json`.

## Build

```sh
brew install xcodegen
cd apps/ios
xcodegen && open Slov.xcodeproj
```

The Xcode project and `Slov/Info.plist` are generated from `project.yml`; never edit or commit them.
Use **Xcode 26** (the iOS 26 SDK) so the Liquid Glass code compiles. The app still runs on iOS 17 to 25 using
`.ultraThinMaterial` fallbacks. All glass vs fallback logic is in `Slov/Design/ChromeSurface.swift`.

## Fonts (Plus Jakarta Sans)

The app looks for these files, declared in `UIAppFonts`:

```
Slov/Resources/Fonts/PlusJakartaSans-Regular.ttf
Slov/Resources/Fonts/PlusJakartaSans-Medium.ttf
Slov/Resources/Fonts/PlusJakartaSans-SemiBold.ttf
Slov/Resources/Fonts/PlusJakartaSans-Bold.ttf
Slov/Resources/Fonts/PlusJakartaSans-ExtraBold.ttf
```

1. Download the family from https://fonts.google.com/specimen/Plus+Jakarta+Sans (Get font, Download all).
2. Unzip. Copy the five static TTFs above from the `static/` folder into `Slov/Resources/Fonts/`.
3. Run `xcodegen` again so the files are added to the target.

Without the TTFs the app falls back to the system font automatically (see `Design/Typography.swift`).

## Strings

- The parent app is English + Hindi. User-facing text lives in `Slov/Resources/Localizable.xcstrings` (`en` and `hi`, keys like `home.today`).
  Views call `L.t("key")` / `L.f("key", args...)` (`App/Strings.swift`), which read the language chosen in the app, not the device language;
  avoid hard-coded text and add both languages for every new key. Dates come only from `IST` and money from `Money` (en_IN or hi_IN).
- The choice is `LanguageStore` (`App/LanguageStore.swift`, `UserDefaults` key `slov.lang`). First launch shows `LanguageChooserView`;
  after that the `EN | हि` switch on Home and Login and the picker in Settings change it with no restart (tabs are rebuilt via `.id`).
  The staff placeholder stays English (`L.t(key, in: .en)`).

## Notifications and push

- In-app: bell on Home (unread dot) > notification centre (filter by selected child or all children, "Mark all read", tap to deep-link).
  Settings > Notifications has one switch per category (all on by default; stored in `UserDefaults` as `notify.<category>`).
  Texts are built from the type plus fields in `Domain/AppNotification.swift`.
- Push setup (the app only asks for permission and registers; the backend does not exist yet):
  1. In the Apple Developer account enable **Push Notifications** for `tech.slov.app` and create an APNs key (.p8) for the backend.
  2. `project.yml` already declares the `aps-environment` entitlement (development) and `remote-notification` background mode.
     Use `production` for App Store / TestFlight builds. `Slov/Slov.entitlements` is generated by xcodegen (git-ignored).
  3. In Xcode check Signing & Capabilities shows Push Notifications. Push does not work on the simulator.
  4. The token goes to `Repository.registerDevice(token:platform:)` after login (`ApiRepository` is a stub that throws).
  5. Payload keys: `type`, `childId`, `deepLink` (`slov://attendance`, `fees`, `notices`, `exams`, `results`, `feedback`, `messages`).

## Fee receipts and exam date sheet

- Fees > invoice > **Download receipt** builds a one-page A5 PDF (`Features/Fees/ReceiptPDF.swift`, `UIGraphicsPDFRenderer`) and opens the
  system share/save sheet. Money is printed as `Rs.` and the amount in words is English.
- More > Notices & calendar > **Exams** shows the selected child's class date sheet (IST date, weekday, start time).

## Leave, report card, timetable, fees detail

- More > **Leave**: list, apply sheet (IST calendar-date pickers, half day only for a single day, reason max 200 with counter) and cancel
  for pending requests. Rules live in `Domain/Leave.swift` (`LeaveRules`) and are enforced again in the mock repository. The row shows a
  pending-count pill. A child who left school gets a note and no apply button. Notification kinds: leave approved / rejected (Attendance
  switch) and report card ready (Results switch).
- Results > exam > **Download report card**: A4 PDF (`Features/Results/ReportCardPDF.swift`) with subjects, total, percentage, overall grade
  (`Domain/Grading.swift`), attendance % for the three months up to the publish month (half day = 0.5) and the remark; shared with `ShareSheet`.
- More > **Timetable**: Monday to Saturday grid that scrolls sideways, today highlighted, "Substitute: name" for today's substitutions.
  Period times are IST clock text ("09:00") shown as stored, never converted.
- Fees detail: fee heads, discounts (negative), late fee, previous dues, total; payments with mode, reference, receipt no and IST time.
  Cancelled payments are struck through, labelled "Cancelled by school", have no receipt button and do not count in Paid or Balance.

## Messages

- Messages tab: an **Updates** row pinned at the top (latest item, unread count) opens the unified feed (school and class broadcasts,
  filter chips All / School / each subject, no replies). Below, **Teachers** (class teacher first, subject chip, last message, unread dot)
  open a chat. **Previous teachers** are greyed with "No longer teaches {Subject}" and open read-only with the explanation instead of the
  composer. A child who left school is read-only everywhere. The mock repository rejects `sendMessage` for inactive threads.
- Notification kinds `broadcast` ("{Sender} · {Subject}" or "School notice" plus a preview) and `message` ("{Teacher}" plus a preview)
  open the Messages tab; both follow Settings > Notifications > Messages.

## Rules enforced in code

- `*_at` UTC ISO strings are shown only through `IST` (Asia/Kolkata). `*_on` dates are never zone-shifted.
- Money is integer paise, shown via `Money.format` as `₹18,500` (en_IN grouping).
- Parents are read-only except messaging (personal threads) and changing password.
- No shadows. Flat grey cards. Orange only for the active tab, primary action and key highlights.
